# 第6周周报

第6周（2026-10-05—2026-10-11）推进 Ariane/MINOTAuR 批量结果整理、bsort 波形分析与论文阅读：[批量结果](../minotaur/results.md)的已确认汇总包含151条历史运行记录、51个不同测例，历史记录不能当作最终测例数；实验排除 mpeg2、susan（susan 为 Ariane TIMEOUT / MINOTAuR MISSING，不计入有效测例成功率），排除后50个有效测例均获双分支 OK，其中29个 Ariane LSU inversion 检测计数非零，MINOTAuR 的50个测例均为0，说明本次测试中相关检测现象受到抑制，不能宣称消除了所有时序异常；按每个测例计算 MINOTAuR/Ariane 执行周期相对增幅再等权统计，平均约9.72%、中位数约8.35%，执行周期与宿主机仿真耗时分别记录，不能直接称为 WCET。本次更新环境无法访问服务器 CSV，保留历史表及已确认代表性结果，完整最新配对表待补。[bsort 波形](../minotaur/bsort.md)已使用 Questa 定位 Ariane 的 `dcache_load_delayed` 首次拉高约在65060 ns，连续检测区间约65060–65140 ns，计数由0增至1再增至2，`lsu=2` 是同一连续区间内的两个计数周期，不能写成两次独立 inversion 或 timing anomaly；两分支总提交指令数均为52180，`bsort.mem` SHA-256 已核对一致，MINOTAuR 对应波形对照与完整请求因果分析尚缺完成证据。[阅读整理](../papers/README.md)围绕 MINOTAuR、LLVM-TA 工具及 Lavinium、A POP⋆ is Born、Leveraging LLVM’s ScalarEvolution for Symbolic Data Cache Analysis、A Predictable SIMD Library for GEMM Routines、S3：Real-Time Neural Network Inference on a Custom RISC-V Multicore Vector Processor 六个主题推进精读，具体状态按现有笔记与证据区分；博士论文、pWCET 不列为本周完成精读。[LLVM-TA](../llvmta/README.md) 的 my_loop10（WCET=3360、BCET=2193，I/D/L2 miss=3/5/8，3360/3361 差异复核后已消失）及 my_loop100（WCET=23578、BCET=22213，miss=5/5/10）是此前工具验证，my_loop1000 尚未运行，也尚未建立匹配 MINOTAuR 的硬件分析模型。下一步补齐最新有效结果与配置/输入核对信息，完成两分支波形对照及请求因果分析，开展受控局部延迟实验并比较程序整体完成时间，以验证严格意义上的时序异常，同时继续整理六个主题的原文、已读章节、方法假设与局限。
