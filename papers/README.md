## 阅读状态说明

- 待阅读：已收集论文，尚未完成正文阅读。

- 方法阅读中：正在理解模型、方法及关键假设。
- 精读：能够结合正文解释方法、实验、局限及与当前课题的联系。

主题讨论、辅助解读与原文阅读分别记录，不将主题讨论直接标记为精读。

## 单篇论文记录格式

每篇论文按以下项目记录：

1. 题目、作者、年份、会议或期刊、原文链接。
2. 阅读日期、已读章节和当前状态。
3. 背景与问题：已有方法为什么不够？
4. 方法：作者增加或改变了什么？
5. 结果：实验或证明支持了什么结论？
6. 假设与局限：结果依赖哪些条件？
7. 与当前工作的联系：可以借鉴什么？
8. 未理解之处与下一次阅读目标。
