# 时间可预测性相关文献阅读

## 阅读目的

围绕当前三条工作线，重点理解：

- inversion与timing anomaly的定义、形成条件及抑制机制。
- WCET分析需要哪些程序信息、硬件模型和假设。
- 面向智能算子时，计算与访存行为如何影响时间可预测性。

## 阅读状态说明

- 待阅读：已收集论文，尚未完成正文阅读。
- 初读：已阅读摘要、引言或结论，能够描述主要问题。
- 方法阅读中：正在理解模型、方法及关键假设。
- 精读：能够结合正文解释方法、实验、局限及与当前课题的联系。

主题讨论、辅助解读与原文阅读分别记录，不将主题讨论直接标记为精读。

## 单篇论文记录格式

每篇论文按以下项目记录：

1. 题目、作者、年份、会议或期刊、原文链接。
2. 阅读日期、已读章节和当前状态。
3. 背景与问题：已有方法为什么不够？
4. 方法：作者增加或改变了什么？
5. 结果：实验或证明支持了什么结论？
6. 假设与局限：结果依赖哪些条件？
7. 与当前工作的联系：可以借鉴什么？
8. 未理解之处与下一次阅读目标。
